Built with

Set a price once. It keeps checking.

Every few hours it takes a snapshot of current deals, looks up each game on your watchlist, and tells you what changed.

Watchlist alerts

Add a game and a target price. Watched games are looked up directly on every fetch, so they're tracked even when they aren't trending.

Discord notifications

Alerts arrive with cover art, the price, and a link to the deal. A game alerts once, then again only if it drops further.

Real historical lows

Uses CheapShark's record of each game's lowest price, so you can tell a real low from a routine sale.

Baldur's Gate 3
$41.99 at GOG Historical low

Store comparison

See which stores have the most deals right now and who's discounting deepest.

Price history

Each fetch is saved as a snapshot, so the dashboard can chart a game's price at every store over time. Leave the scheduler running and the history builds itself.

$ python main.py schedule --hours 6

Prefer the terminal? Everything works there too.

Every report in the dashboard is also a command: top deals, historical lows, price history, store summaries, and the watchlist.

$ python main.py watch add "Baldur's Gate" 45

Four steps to your first alert.

You'll need Python 3.10 or newer. CheapShark is free and doesn't need an API key.

  1. Install

    git clone https://github.com/JMScripts1/game-deal-tracker.git
cd game-deal-tracker
pip install -r requirements.txt

  2. Watch a game

    python main.py watch add "Hades II" 20

  3. Connect Discord

    Optional. Create a webhook in your channel's settings, then add it to a .env file and send a test message.

    DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...
python main.py test-discord

  4. Fetch and open the dashboard

    python main.py fetch
streamlit run dashboard.py
